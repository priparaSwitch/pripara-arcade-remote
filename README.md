# pripara-arcade-remote

프리파라 아케이드의 코디 화면에서 의상과 의상세트를 선택해 현재 마이캐릭터에게 입히는 Windows 프로그램입니다. 현재 소스 버전은 **1.1.3**입니다.

게임에 있는 의상 카탈로그를 검색하고, 선택한 코디를 실행 중인 게임의 의상 선택 처리에 전달합니다. 게임 파일을 교체하거나 세이브를 편집하지 않습니다.

## 주요 기능

- 의상세트와 개별 의상 선택, 이름·ID 검색, 브랜드 필터.
- **즐겨찾기 → 의상세트 → 전체 → 헤어 액세서리 → 상의 원피스 → 하의 → 슈즈** 탭.
- ID·이름·등급 기준 정렬과 오름차순·내림차순 전환.
- 선택 즉시 전송 또는 선택한 코디를 모아 전송.
- 원피스와 하의의 중복 선택 방지, 지원되는 의상세트 자동 맞춤.
- DEBUG ON/OFF 모두 지원하는 MyChara 코디 전송.
- 타이틀과 화면 우측 상단에 프로그램 버전 표시.

카드의 별표는 즐겨찾기만 바꾸며 의상을 전송하지 않습니다. 즐겨찾기는 사용자별 로컬 설정에 저장합니다. 현재 데이터의 세트 대표 상의는 전체·상의 목록에서 숨기며, 일반 개별 상의는 그대로 표시합니다.

## 파일 구성과 사용

| 파일 | 역할 |
| --- | --- |
| `프리파라 코디 리모컨.exe` | 화면과 게임 연결 처리 |
| `data.db` | 필수 SQLite 카탈로그: 의상·세트·검색·부위 정보 |
| `images.bin` | 선택 사항인 썸네일 묶음 |

EXE와 `data.db`를 같은 폴더에 두고 실행합니다. `images.bin`이 없어도 의상 목록 검색과 게임 전송을 사용할 수 있으며, 그림이 없거나 손상된 항목은 대체 표시합니다. 형식에 맞는 DB와 이미지 파일로 교체한 뒤 프로그램을 다시 실행하면 데이터를 갱신할 수 있습니다.

게임에서 코디 화면을 연 뒤 리모컨의 연결 상태를 확인하고 의상을 선택합니다. 전송 대상은 **MyChara**입니다. 장면 전환 중이거나 다른 캐릭터 타입을 선택한 상태에서는 연결 안내를 확인해야 합니다.

Windows 10/11 x64, .NET Framework와 Windows 내장 SQLite 구성 요소를 사용합니다. Python이나 별도 SQLite DLL은 필요하지 않습니다. 실행 시 관리자 권한을 요청하며, 게임 프로세스에 접근할 수 있는 권한이 필요합니다.

## 구현 구조

| 위치 | 담당 기능 |
| --- | --- |
| `src/Program.cs` | C# WinForms 화면, 검색·필터·정렬, 코디 선택 |
| `src/Catalog.cs` | SQLite 카탈로그 검증과 이미지 읽기·캐시 |
| `src/GameBridge.cs` | 실행 중인 게임 탐색, 상태 검사, 의상 선택 전달 |
| `src/Favorites.cs` | 즐겨찾기의 로컬 저장·복원 |
| `assets/` | 교체 가능한 DB·이미지·데이터 메타정보 |
| `tests/`, `src/SelfTests.cs` | 데이터와 전송 로직의 오프라인 검증 |

게임 연결은 설치 경로를 고정하지 않고 실행 중인 **`Prineo` 프로세스**를 찾습니다. 실행 모듈의 실제 시작 주소에 기준 오프셋을 적용하고, 코디 처리부의 짧은 명령 서명과 현재 Scene·캐릭터·아이템 표를 확인합니다. 전체 EXE 해시의 허용 목록을 사용하지는 않지만, 내부 구조가 다른 모든 버전을 지원한다는 뜻은 아닙니다.

전송할 때 카탈로그의 아이템 ID를 게임 안의 실제 의상 행과 대조합니다. 현재 코디 화면이 유지되는지 다시 확인한 뒤 네 부위의 선택값과 적용 요청을 전달하고, 게임의 반영 상태를 확인합니다. 게임 코드를 주입하거나 DEBUG 플래그를 강제로 바꾸지 않습니다.

카탈로그는 Windows의 `winsqlite3.dll`로 읽습니다. `images.bin`은 아이템 ID별 PNG를 담은 ZIP 컨테이너이며 필요한 그림을 읽어 캐시합니다. 실행 시 특정 DB 파일의 전체 해시나 항목 수를 고정하지 않으며, 데이터 형식 1을 확인합니다. 이 형식을 유지하면 EXE 변경 없이 카탈로그를 바꿀 수 있습니다. 자세한 형식은 [데이터 형식 문서](docs/DATA_FORMAT.md)를 참고하세요.

## 지원 범위

- 게임의 내부 코디 구조가 호환되고, 해당 게임에 실제로 존재하는 의상만 전송할 수 있습니다. DB에 항목을 추가하는 것만으로 게임에 모델이 생기지는 않습니다.
- 현재 동봉 DB에는 실제 등급값이 없어 등급 정렬이 ID순서로 표시됩니다. `item_meta.grade`를 제공하는 호환 DB에서는 해당 값을 사용합니다.
- 게임·가상카메라·QR 도구는 별도 구성입니다. 이 프로그램은 게임 실행기나 패처가 아닙니다.
- 오프라인 검증은 실제 게임 화면에서 모든 의상과 모든 버전이 정상 동작한다는 보장이 아닙니다.

프로젝트 전체 라이선스는 아직 지정하지 않았습니다. 포함된 소스·데이터·구성요소의 권리와 라이선스는 [구성요소 안내](THIRD_PARTY_NOTICES.md)를 확인하세요.
