# 외부 데이터

`data.db`는 필수이고 `images.bin`은 선택 사항입니다. 둘 다 EXE에 내장하지 않습니다.

현재 데이터는 아이템6,229개·세트823개, 이미지5,783개입니다. `images.bin`은 최대128×128·256색 PNG를 ID별로 담은 ZIP 컨테이너이며 24,855,484바이트입니다. 밝은 의상의 명암을 보존하는 기존 adaptive 최적화를 그대로 사용합니다.

`manifest.json`의 크기·해시는 **동봉한 릴리즈 데이터의 검증 기준**입니다. 앱의 일반 실행 로더에 해시나 개수를 강제하는 기능이 아닙니다. 형식1을 지키는 별도 데이터로 바꾸려면 [데이터 형식 문서](../docs/DATA_FORMAT.md)를 참고하세요.

이 저장소의 데이터는 기존1.1.1과 바이트가 같습니다. 과거 로그·개인 경로·게임 EXE는 데이터 출처로 함께 넣지 않았습니다.
